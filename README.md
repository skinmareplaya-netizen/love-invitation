# Нежно-розовое приглашение 💗

Готовый мобильный сайт: конверт → письмо с извинением → вопрос → приглашение → детали встречи → подтверждение. Ответ «нет» **не убегает**: выбор девушки остаётся свободным.

## 1. Изменить встречу
Откройте `config.js` и измените `date`, `time`, `place`, `after`. Сейчас установлены среда 11 ноября 2026, 17:00, возле лицея, затем Поворот. Измените дату, если встреча будет в другую среду.

## 2. Опубликовать на GitHub Pages с Android
1. Распакуйте ZIP в приложении «Файлы» или ZArchiver.
2. На github.com откройте свой профиль → **Repositories** → **New**. Название, например, `pink-invite`. Выберите **Public** → **Create repository**.
3. Нажмите **Add file → Upload files**. Загрузите `index.html`, `style.css`, `script.js`, `config.js` **в корень репозитория** (не всю папку и не ZIP). На Android может потребоваться «Версия для ПК» в браузере. `telegram-worker.js` можно также сохранить в репозитории, но он не нужен для работы страниц.
4. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
5. Через несколько минут адрес будет вида `https://USERNAME.github.io/pink-invite/`. Откройте его и проверьте.

## 3. Уведомления в Telegram (необязательно)
GitHub Pages — статический хостинг, поэтому не может безопасно хранить токен бота. **Никогда не вставляйте токен Telegram в HTML, JS или публичный GitHub-репозиторий.** Для уведомлений нужен серверный обработчик, например Cloudflare Worker (есть бесплатный тариф с лимитами).

1. В Telegram откройте официального `@BotFather`, отправьте `/newbot`, создайте бота и **сохраните токен только у себя**.
2. Напишите своему боту `/start`.
3. Узнайте `chat_id` через `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` в своём браузере. В ответе найдите `message.chat.id`. **Никому не отправляйте этот URL или его скриншот: он содержит токен.**
4. В Cloudflare Dashboard откройте **Workers & Pages → Create → Worker**. Создайте Worker, откройте **Edit code**, замените код содержимым `telegram-worker.js`, нажмите **Deploy**.
5. В **Settings → Variables and Secrets** добавьте `TELEGRAM_BOT_TOKEN` (Secret), `TELEGRAM_CHAT_ID` (Secret), `ALLOWED_ORIGIN` (Text). Последнее — только источник сайта без пути и слеша на конце, например `https://USERNAME.github.io`.
6. Скопируйте HTTPS-адрес Worker, например `https://pink-notify.example.workers.dev`, и вставьте его в `config.js` как `notificationEndpoint`. Сохраните изменение на GitHub.
7. Проверьте сайт: при выборе финального ответа бот должен прислать сообщение. Если endpoint пустой, сайт работает без Telegram.

### Важно о безопасности
- Worker проверяет источник запроса и допустимые ответы, но **это не полноценная защита от спама**: HTTP-клиенты могут подделывать Origin. Для публичного запуска добавьте rate limiting и защиту от ботов, например Cloudflare Turnstile с серверной проверкой.
- Ответы отправляются без имени, телефона и геолокации. Уведомление не гарантировано при сбоях сети; сайт не заявляет, что сообщение доставлено.
- Ссылка на GitHub Pages общедоступна. Не размещайте в ней личные адреса и другую чувствительную информацию.

## Локальная проверка
Откройте `index.html` в браузере. Для уведомлений нужен опубликованный сайт и настроенный Worker.
